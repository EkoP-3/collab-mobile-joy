# Momentum

Türkçe alışkanlık takibi ve günlük planlama uygulaması (TanStack Start + React + Supabase + Firebase push).

## Geliştirme

```sh
bun install
bun run dev
```

Gerekli ortam değişkenleri için `.env.example` dosyasına bakın.

## Komutlar

- `bun run dev` – geliştirme sunucusu
- `bun run build` – üretim derlemesi
- `bun run lint` – ESLint
- `bun run format` – Prettier
